- **Remixes were silently stuck on the fastest, lowest-quality engine setting.** The remix path never passed a `quality`, so every remix ever made ran on the turbo model at 8 inference steps, and the `cover` path hardcoded them. Worse, naming a model in the render request isn't enough — the engine ignores a model it hasn't initialised and quietly renders with whatever is resident, logging the fallback where nothing surfaced it. Both are fixed: a Fast/Studio choice on the Remix screen, and the provider now switches the model explicitly and fails loudly if it can't.
- **Transcription could invent lyrics.** Forced to the wrong language Whisper does not fail — it confabulates. A 3:30 Urdu song mislabelled English came back as six copies of "Pakistan 345, base 7, 30 start push for Karachi" plus two half-translated lines, and a whole song got built from it. Riff now detects the language from the audio and trusts that over the dropdown (adopting it for the re-sing too), never translates, breaks Whisper's repetition loop, and warns when a transcript is too short for the song's length.
- **Mastering flattened the music.** Single-pass `loudnorm` rides the level bar by bar; measured against a commercial reference our masters had 4.9 LU of loudness range against 6.4. It now measures first and applies one static gain, so the arrangement's own builds and drops survive.
